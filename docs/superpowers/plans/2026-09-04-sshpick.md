# sshpick Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `sshpick`, a Go TUI that filters `~/.ssh/ssh_hosts` by substring and runs `ssh <host>` on Enter.

**Architecture:** Split into `hosts` (file I/O), `filter` (matching), `tui` (Bubble Tea UI), `sshcmd` (exec), and `main` (wiring). Educational comments explain Go and TUI concepts for learners.

**Tech Stack:** Go 1.22+, Bubble Tea, Lip Gloss (optional light styling)

## Global Constraints

- Hosts file path: `~/.ssh/ssh_hosts` (read-only; never create/overwrite)
- Substring match, case-insensitive; empty query → no results
- Enter always required; Esc/Ctrl+C quits
- Binary name: `sshpick`
